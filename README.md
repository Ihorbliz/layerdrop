# Сайт Layerdrop - HTML to Layout

Статичний сайт без збірки. Українська лежить у корені, англійська в `en/`. Приватність: `privacy/` і `en/privacy/`. План розвитку: `roadmap/` і `en/roadmap/`.

Стилі: `assets/site.css`, за `docs/design-system.md`. Якщо змінюєш CSS, збільш `?v=` у посиланні на нього на всіх сторінках, інакше браузери покажуть стару версію. Перегляд: `py -m http.server 4180 --directory site`.

## Що замінювати

| Що | Де |
|---|---|
| План розвитку | Лише список у `assets/roadmap-items.js`, верстку чіпати не треба |
| Посилання на Figma Community | Лише `COMMUNITY_URL` в `assets/community-link.js`. Поки воно порожнє, сайт пише, що плагін не опублікований. З посиланням з'являються кнопки, а написи зникають |
| Скриншоти | `assets/shots/`, таблиця нижче |
| Адреса сайту | `https://ihorbliz.github.io/layerdrop/` у `<head>` чотирьох сторінок, `robots.txt`, `sitemap.xml`, а також `<base>` у `404.html` |
| Версія | Рядок у футері `index.html` і `en/index.html` |
| Порівняння | Таблиця в обох `index.html`. Дату в рядку над таблицею оновлюй разом із даними |

## Скриншоти

Щоб замінити картинку, поклади PNG із такою самою назвою й пропорціями. Рожевий аркуш і загнутий кут малює CSS (`.sheet`), на самих картинках їх немає. Якщо пропорції інші, онови `width` і `height` у тегах `<img>` на обох мовах.

| Файл | Розмір | Що показує |
|---|---|---|
| `hero-figma.png` | 1523×711 | Перший екран: справжній імпорт демосторінки у Figma, знятий із застосунку |
| `frame-1920.png` | 1920×864 | Демосторінка на ширині 1920, лише для `share-cover.png` |
| `frame-768.png` | 768×941 | Демосторінка на ширині 768 |
| `frame-390.png` | 390×829 | Демосторінка на ширині 390 |
| `window.png` | 570×841 | Вікно плагіна після того самого імпорту |
| `fonts-warning.png` | 627×152 | Блок про відсутні шрифти |
| `viewport-bar.png` | 904×100 | Перемикачі viewport |
| `share-cover.png` | 1920×1080 | Картинка для соцмереж |

Кадри `frame-*` це вигляд вигаданої сторінки `tools/demo/index.html` у браузері, а не результат імпорту. `hero-figma.png` і `window.png` зняті з Figma після її справжнього імпорту. Після публікації їх варто зняти ще раз, бо зараз у заголовку вікна написано Developer VM.

Скрипти в `tools/` працюють лише в основному репозиторії: `render-shots.py` малює кадри й обкладинку, `crop-shots.py` вирізає перемикачі й блок шрифтів зі слайдів `docs/community/`.

## Шрифти

Лежать в `assets/fonts/`, ліцензії поруч (`OFL-*.txt`). В Anton немає кирилиці, тому українські заголовки набрані Fira Sans Extra Condensed 900, а логотип лишається в Anton.

## Публікація

Сайт живе в окремому публічному репозиторії `Ihorbliz/layerdrop`, куди потрапляє лише вміст цієї папки без `tools/`. Основний репозиторій приватний. Workflow `.github/workflows/pages.yml` викладає сайт після кожного пушу в `main`, README на сайт не потрапляє.

Коміти в публічний репозиторій роби зі службової адреси GitHub, щоб особиста пошта не потрапила в історію:

```bash
git config user.email "67855226+Ihorbliz@users.noreply.github.com"
```
