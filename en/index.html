Layerdrop - HTML to Layout. A Figma plugin

Drop a file.
Get layers

Layerdrop turns HTML, saved websites, archives and emails into editable Figma layers. Styles are kept: colors and text become local styles, and the result looks like the page in a browser.

See what it does Open on Figma Community

The plugin is being prepared for Figma Community and can't be installed yet.

What lands in Figma

The plugin opens the page the way a browser shows it and builds layers from that. The page stays whole: nothing gets split into pieces or cropped.

  • Styles are kept
    A color or text setting that appears at least twice becomes a local Figma style. Layers are linked to those styles right away, and importing the same page again reuses them. You can turn this off.
  • Section and frames
    Each file becomes a section holding one frame per selected viewport. A frame is as wide as its viewport and as tall as the page.
  • Auto layout
    Containers are broken down into nested rows and columns, including grids and blocks with uneven gaps. Auto layout stays only where no layer moved by more than 1 px. Overlapping layers stay absolute. You can turn this off.
  • Layer names
    Layers are named after what they contain: Header, Button · Get started, H2 · Pricing. Utility classes like css-1a2b stay out of the names.
  • Gradients and SVG
    Linear, radial and conic gradients arrive as real Figma gradients, so you can edit their colors and stops. SVG becomes vector, not a picture.
  • Missing fonts
    If a font isn't in Figma but its file is in the HTML or zip, the text arrives as outlines next to a hidden text layer. The plugin lists what to install, and the "Update fonts" button makes the text editable.
  • Failures
    A broken element, file or font doesn't stop the import. The plugin skips what failed and describes it in the warnings.

Any width

The presets are 1920, 1440, 1024, 768 and 390. Click to switch a viewport on or off, or click its number to set your own width.

A responsive page reflows as it does in a browser. A non-responsive one keeps its size and runs past the frame edge without being cropped.

Two routes

Drop a file

For finished pages, saved websites and pages behind a login. Anything your browser can open, you can save and import.

  • Images, stylesheets, fonts and scripts in a folder or zip are picked up by relative path.
  • A single file from the SingleFile extension already contains its images, styles and fonts.
  • To add a folder, just drag it into the window.

Paste code

For snippets, email templates and generated markup. On the Code tab, paste HTML and click "Import to Figma".

  • There are no files next to pasted code, so local paths won't work.
  • Images must be embedded as base64 or sit behind an https link on a server that allows CORS.

What you can drop

  • HTML
    .html, .htm, one file or several, each imported separately. You can also select HTML together with its images.
  • Saved websites
    .mhtml, .mht, or HTML from SingleFile.
  • Folders and archives
    A folder or .zip, including a Google Stitch archive. The top-level index.html is imported, or every HTML file if there isn't one.
  • Emails
    .eml, .emlx, .msg. The frame takes its name from the subject.

How it works

  1. 1
    Pick one or more viewports.
  2. 2
    Change the layer settings if you need to: auto layout and local styles. Your choice is remembered.
  3. 3
    Drop a file into the window and click "Import". Files stay in the list, so you can import them again with other viewports.
  4. 4
    A section appears on the canvas. The window shows how many frames, layers and new styles were made, and warns you if something didn't transfer.

The plugin opens the page in an isolated frame, where its scripts run and the browser lays it out at the width you chose. Then the plugin reads the result and builds layers from it. Scroll animations appear in their final state.

Questions

How much does it cost?
There will be two versions: Freemium and Pro. We'll announce what each one includes later.
Can I paste a URL?
Import by URL is in development. For now, save the page with SingleFile and drop the file: its scripts have already run, and this works for pages behind a login too.
Where do my files go?
Nowhere, because the plugin has no server to send them to. The only requests come from the page itself and, for a font that failed to load, from the plugin to Google Fonts. See the privacy policy for details.
Is it safe to run a page's scripts?
The page runs in an isolated frame and can't reach the plugin or your Figma file. But its scripts can make their own internet requests, and an infinite loop can freeze the window. Don't import pages you don't trust.
Why did my images turn gray?
The plugin couldn't get the file: there was no folder next to it, or the server doesn't allow CORS. Drop a folder or zip, or save the page with SingleFile, which embeds images in the file.
Why are there Row and Column frames?
They keep elements in place when a grid or uneven blocks get broken down into nested rows and columns. If they get in the way, turn off auto layout in the layer settings.
Does it work in Figma in the browser?
So far we've only run it in the Figma desktop app. We'll confirm this after publication.
What languages does the window support?
English and Ukrainian, with a switch at the top. Layer names and canvas notifications are always in English, and text from the page isn't translated.
Can I import someone else's website?
Technically the plugin imports whatever you can open. Whether you have the right to depends on the site and your purpose. Respect copyright and trademarks.
