Privacy

Layerdrop has no server of its own, no accounts and no analytics. Your files stay on your computer and in your Figma file.

What the plugin does

  • Your files
    HTML, archives, emails and pasted code are processed locally in the plugin window. They aren't sent to us, because there is nowhere to send them.
  • Your Figma file
    The plugin creates layers and styles in it. Data from your Figma file isn't sent anywhere.
  • What is stored
    On your device, in Figma's plugin storage: your language and layer settings. In the layers themselves: which fonts are needed, for the "Update fonts" button.
  • Analytics
    None. The plugin collects no usage statistics and needs no sign-up.

What requests happen

To make a page look the way it does in a browser, the plugin opens it in an isolated frame. So the network is still used:

  • Page resources
    Images, stylesheets, fonts and scripts the page links to load from where they're hosted. Those servers can see the requests, just as when the page opens in a normal browser.
  • Google Fonts
    If a font fails to load, the plugin requests it from Google Fonts by name. The contents of your files aren't sent.
  • Page scripts
    They run in an isolated frame (sandbox="allow-scripts") and can't reach the plugin or your Figma file. But they can make their own internet requests and send what's on the page itself. Don't import pages you don't trust.
  • Network access
    Figma shows an Unrestricted label for the plugin, because a page can link to any domain and those can't be known in advance.

This website

  • What's here
    Static pages. No forms, cookies or analytics. Fonts are served from this site.
  • Hosting
    The site is hosted on GitHub Pages. GitHub may process technical visit data, including your IP address, under its own policy.
